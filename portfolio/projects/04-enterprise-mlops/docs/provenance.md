# Portfolio provenance and claims

This project is newly authored portfolio reference code, independent of any employer source or private production service.

**What exists:** Validated features -> deterministic train/split -> evaluation quality gate -> immutable registry -> inference; tests in `tests/test_app.py`.

**What remains:** Connect to Azure ML pipelines, managed online endpoints, Key Vault, feature store and monitoring.

**Limitations:** Reference baseline uses standard-library logistic regression; no Azure ML job or online model deployed.

Do not describe this project as a four- or five-year production deployment or claim measured users, performance, uptime, savings, AI accuracy, or business outcomes without independently collecting data.
