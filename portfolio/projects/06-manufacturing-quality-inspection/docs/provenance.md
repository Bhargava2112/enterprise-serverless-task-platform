# Portfolio provenance and claims

This project is newly authored portfolio reference code, independent of any employer source or private production service.

**What exists:** Camera/P2 PGM -> image validation -> feature extractor -> trainable classifier -> audit-ready inspection decision; tests in `tests/test_app.py`.

**What remains:** Collect labeled images, augment, evaluate production CV model, deploy on Azure IoT Edge or Azure ML.

**Limitations:** Trainable visual baseline using P2 grayscale; not a validated production deep-learning vision model.

Do not describe this project as a four- or five-year production deployment or claim measured users, performance, uptime, savings, AI accuracy, or business outcomes without independently collecting data.
