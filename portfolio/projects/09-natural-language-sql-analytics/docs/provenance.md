# Portfolio provenance and claims

This project is newly authored portfolio reference code, independent of any employer source or private production service.

**What exists:** Natural question -> controlled semantic planner -> SQL compiler -> read-only bound SELECT -> report; tests in `tests/test_app.py`.

**What remains:** Add a constrained intent parser/LLM proposal stage, SQL AST validation, role-based row filters and warehouse adapters.

**Limitations:** Uses a rule-based natural-language compiler, not an LLM, and a sample SQLite database.

Do not describe this project as a four- or five-year production deployment or claim measured users, performance, uptime, savings, AI accuracy, or business outcomes without independently collecting data.
